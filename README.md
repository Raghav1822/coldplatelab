# ColdPlateLab

**A MATLAB-backed design explorer for liquid-cooled cold plates.**

Browse and compare serpentine, parallel-channel, and pin-fin concepts for CPUs, GPUs, batteries, and data centers. The public website runs as a static GitHub Pages site. MATLAB is the source of truth for the concept library and pump-estimate lookup data; the browser reads MATLAB-exported JSON so no MATLAB server or license is needed to view the site.

## Live website

https://raghav1822.github.io/coldplatelab/

## Features

- Search, filter, and sort eight concept designs by geometry, application, and thermal/hydraulic metrics.
- Select designs for a side-by-side comparison.
- Explore flow-path schematics and engineering trade-offs.
- Adjust flow, coolant density, and pump efficiency; the website reads pressure-drop and electrical-power results precomputed by the MATLAB model.
- Run the same estimator in the optional MATLAB desktop UI.

## Regenerate the MATLAB data

Requires MATLAB R2020a or newer; no add-on toolboxes are required.

1. Set MATLAB's current folder to the repository root.
2. Run:

   ```matlab
   coldplatelab_export
   ```

3. Commit the updated files in `data/` and push to `main`. GitHub Actions republishes the website automatically.

The export script creates `data/designs.json` and `data/pump-estimates.json`. The pump lookup covers flow rates from 0.5 to 3.0 L/min in 0.1 L/min steps, coolant densities from 850 to 1200 kg/m³ in 50 kg/m³ steps, and pump efficiencies from 20% to 70% in 5% steps. Website controls use those exact increments so displayed estimates come directly from the MATLAB-generated lookup.

For the optional MATLAB desktop explorer, run `coldplatelab` from the repository root. Run its calculation checks with:

```matlab
addpath('tests')
run_smoke_tests
```

## Engineering model and limitations

The eight built-in entries are **synthetic, illustrative concept-stage inputs**, not measured product specifications or validated simulation results. Pump pressure drop is scaled from each design's reference point:

```text
deltaP = referenceDeltaP * (flow / referenceFlow)^2 * (coolantDensity / 997 kg/m^3)
hydraulicPower = deltaP * volumetricFlow
estimatedElectricalInput = hydraulicPower / pumpEfficiency
```

The model is a transparent comparison aid—not a substitute for CFD, bench measurements, coolant-property models, or pump curves. Estimates exclude external plumbing losses. Temperature spread and thermal resistance are illustrative reference values and do not change with estimator controls.

## Files

- `coldplatelab.m` — optional native MATLAB desktop explorer.
- `coldplatelab_data.m` — shared illustrative design library.
- `coldplatelab_estimate.m` — validated pressure-drop and pump-input model.
- `coldplatelab_export.m` — MATLAB JSON exporter for the website.
- `index.html`, `styles.css`, `app.js` — static interactive website.
- `data/` — checked-in website data assets generated by MATLAB.
- `.github/workflows/pages.yml` — automatic GitHub Pages deployment.

MATLAB generates the JSON assets; HTML, CSS, and JavaScript provide the browser interface because GitHub Pages cannot execute MATLAB code.
